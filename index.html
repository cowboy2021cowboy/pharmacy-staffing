Connect the shared board

Do this once. Then send the website link and the PIN to the team. Everyone edits the same numbers.

1. Create a free project at console.firebase.google.com. Click Build → Realtime Database → Create database → start in test mode (test mode expires after 30 days; after that, set the rules to allow read and write, or the board stops saving).
2. Copy the database URL. It looks like https://your-project-default-rtdb.firebaseio.com.
3. Paste it below and set a PIN. Save. Host this file on Netlify Drop so the team has one link.

How to assign and adjust

  1. Type the queue at 7:00 (pending + processing + verified-not-packed).
  2. Put Early heads on Pens and DRG first. Cold must clear by 4pm.
  3. Put remaining Early and Mid on ambient and production.
  4. Watch Done 7:00. Cold done after 16:00 means move people now.
  5. At 11:00 retype the remaining queue and move heads.
  6. Associates do Spark labeling, help RPh Spark, pen line (3 FA per tech), then prepack.

Pen line rate = tech pen rate ÷ 3. Changes sync about every 8 seconds when the board is connected.
